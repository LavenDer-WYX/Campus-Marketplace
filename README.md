# Campus Marketplace

Campus Marketplace is a web application designed for university students to buy, sell, swap, and give away second-hand items within the campus community.

## Tech Stack

- ASP.NET Core MVC
- C#
- SQL Server
- Entity Framework Core
- HTML
- CSS
- Bootstrap
- JavaScript
